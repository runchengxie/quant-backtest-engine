# 成交与估值假设

订单只能在其信息时间之后的第一条对应标的报价上提交。等于信息时间的报价不能成交。
同一时间的报价按输入顺序处理，订单也按输入顺序提交，这会影响现金分配。

买单使用卖价，卖单使用买价。这是 L1 报价模型，不代表日线开收盘成交或订单簿队列。
每侧报价数量固定为 100 万股，不宣称真实成交容量或部分成交精度。

买单准入使用上游手续费计算和拒单接口，检查本金加手续费是否足够。
同一次报价回调中的买单预留所需资金，卖出资金需等上游处理后才可再次使用。
手续费按美元精度取整，适配层不另写撮合和现金账本。

回测结束不强制平仓。剩余持仓按各标的最后买卖报价中间价估值。
不同标的行情结束时间不同时，估值可能使用较早的报价。
中间价估值不表示持仓一定能按该价格卖出。

当前不支持 A 股 T+1、涨跌停、停牌、公司行为、退市、杠杆、多币种、做空和限价单。
信息时间由调用方提供，不能据此证明模型、财报或特征在历史上确实已经可用。
