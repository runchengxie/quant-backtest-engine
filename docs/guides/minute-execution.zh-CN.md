# 分钟执行情景

[English](minute-execution.md)

`quant_backtest_core.backtest.minute` 提供独立、可选的长仓执行情景。它使用原始价格和明确的公司行动，不改变现有日频 API。分钟成交均价是历史成交额除以股数、再限制在该分钟 OHLC 范围内的代理价格，不能据此认定真实委托能成交，更不能识别自身订单的冲击。

入口为 `MinuteExecutionConfig` 和 `simulate_minute_execution(targets, bars, config, corporate_actions=())`。结果包含 `daily`、`orders`、`fills`、`holdings` 与 `summary`。持仓日报仅列正持仓，只有该日期存在于 `daily` 时，缺少证券持仓行才表示零持仓。

`targets` 是完整目标快照，包含 `decision_time`、`entry_time`、`symbol`、`weight`。时间必须为带时区的 pandas Timestamp，下单必须晚于决策。未列出的旧持仓目标为零。新目标取消前一批仍未完成的订单。订单股数按下单之前已经可用的参考价确定，不能读取未来分钟安排释放数量。

`bars` 包含 `symbol,time,open,high,low,close,volume,amount,up_limit,down_limit,tradable`。价格和成交额用元，成交量用股。`time` 是行情可用时点。可另外提供 `interval_start`，表示该行成交量覆盖区间的开始。未提供时保守使用 `time-1分钟`。只有整个成交区间开始时已超过子单释放和延迟的记录才可成交。接收延迟不能把订单生效前的成交量变成可用流动性。

释放计划由 `release_slices` 和 `execution_minutes` 预先确定，时长按墙钟分钟计算，包含午休。每分钟同一证券的订单共享参与率上限。卖出先于买入，买入受含费现金约束。模型检查 T+1、配置的整手及方向对应的涨跌停触及。触及涨停不模拟买入，触及跌停不模拟卖出。整数零股可在整笔清仓且流动性足够时卖出。小数权益保留并单列，不假定能卖出。

公司行动使用已有 `CorporateAction` 合约。在登记日收盘捕获持股，除权日建立应收现金及股票，到账日或上市日转为可用。尚未上市的送股计入目标敞口但不可卖。除权日首条新行情之前的参考价按已知普通分配调整，此时订单标为 `synthetic_ex_reference`，不能将其称为观察到的报价。重整转增、配股及其他特殊分配需由调用方核验，不能套用普通送股。

现金、持仓及待上市股票缺少当日有效估值时，保留缺失净值与证券诊断。调用方还应核对收盘报价、完整交易日历、历史资格、全部公司行动及输入版本。`commission_minimum_cny` 默认零，可选最低佣金按母单聚合，只在首次成交或累计佣金超过最低值时增量收费。`sell_tax_bp` 单列卖出税费，必须不大于卖出总费率。无成交不收费，现金不足时不能执行含费买入或亏现金的卖出。按母单计最低佣金是假设，真实券商可能按子单收费，需用交割单校准。模型不重建真实排队或隐藏流动性；可选 `LinearImpact` 仅用于显式合成冲击情景。


显式估值事件 `ValuationEvent(event_id, symbol, effective_time, available_time, value_per_share, basis, source)` 独立于成交行情，通过 `valuation_events=()` 传入。估值可以为零。两个时间必须带时区，且可获知时间不能晚于生效时间。事件编号及证券／生效时间组合不能重复。事件建立永久不可交易状态，取消相关未成交订单，并阻止后续目标权重触发交易。现金、实际持股与公司行动权益均保留。只有后续估值事件可以更新声明的估值，且不能恢复交易资格。不可交易行情不会覆盖声明估值。生效时点及之后存在可交易行情则严格报错。

区间内的事件在自身生效时点、订单定量之前应用。区间前的声明在首个基础时点建立状态，同时保留原始时间。区间后的事件不扩大结束日期，其编号列入 `summary.ignored_future_event_ids`。持续沿用的声明估值是显式假设，不是每日新行情。启用事件后，`daily.valuation_marks` 保留来源、依据、生效／可获知时间及来源／事件年龄。`valuation_ledger` 记录应用时点、实际股数、应收股票、前后估值、价值变动和保持不变的现金。零值仅代表估值声明，不能写成零价 OHLC，也不代表证券已经处置。

启用估值事件时，行情时间、区间起点和目标的决策／入场时间必须采用同一个声明的市场时区。事件可使用其他时区。引擎将其转换为市场时区，同时保持实际时刻不变，日历日记账始终按市场时区处理。

### 条件订单与信息时间声明

公开入口为 `quant_backtest_core.backtest.minute`。
该入口接收完整目标快照，不是任意经纪商订单。可选目标列 `order_type`
只接受 `market`，显式拒绝 `limit`、`stop`、`stop_limit` 等条件指令。
OHLC 无法确定高低价出现顺序，不能据此推断止损与限价触发先后。
既有保守规则保持不变：买入 bar 触及 `up_limit` 或卖出 bar 触及
`down_limit` 时整根不成交。这两个字段是交易所涨跌停价格，不是订单限价。

可选的带时区 `information_time` 声明形成目标所用信息的最晚时间，必须不晚于
`decision_time`。校验仅约束声明，不能证明底层特征实际何时可用。省略时仍由调用方
负责时点一致性。入场必须晚于决策，定量仅使用入场前已观察价格，成交 bar
必须整体晚于释放加延迟。成交量与成交额在 bar 结束时才已知，VWAP 是事后执行代理。

每次成交都会扣减该标的该 bar 的参与容量。完整快照会取消旧待执行订单，因此公开目标
接口通常每个标的只有一个待执行母单。检验纯费用敏感性时应固定目标、保留现金余量。
现金约束生效时，费用也会改变整手成交数量。合成回归例见
`tests/test_minute_execution_hardening.py`。

## 临时不可交易估值的来源时间

行情表可以同时提供 `mark_source_time` 和 `mark_basis`。`raw` 要求来源时间与行情时间相同。
`declared_nontrading` 要求 OHLC 为同一个价格、成交量和成交额均为零、`tradable=False`，
且带时区的来源时间不晚于该估值的生效时间。调用方负责提供并审计数据来源和公司行为处理口径。

临时停牌估值之后仍可恢复交易。后续订单的参考价格记录保留估值生效时间、原始来源时间和依据。
该声明不是可成交报价，也不认证数据质量。永久不可交易估值事件沿用独立契约。
不提供这两个字段时，既有行为保持不变。

## Engine 归属与合成示例

此接口由 `quant-backtest-core[minute]` 显式提供，财务类型仅在 core 中定义。
Platform 当前仍保留原提供方；其类型、`LinearImpact` 与兼容别名在后续消费者切换时整体迁移。
不导入 Platform、Runtime 或模型训练依赖。此处尚未注册产品运行器的分钟后端。

从已安装 wheel 运行仓库中的合成 CNY 示例：

```bash
python -I -B examples/product/minute_session.py
```

示例包含公司行动、数量锁、报告延迟与外部资金，验证检查点恢复后的完整财务表。
[会话与资金流契约](../backtest/minute-session.zh-CN.md)说明时钟和恢复限制。
旧 `minute-session.v2` 必须使用原先固定的完整提供方环境，不允许改写摘要或静默迁移。
