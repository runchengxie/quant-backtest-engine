# 解析清算参考实现计划

[English](2026-11-23-control-reference.md)

目标：为 `quant_backtest_core.planning.liquidation_reference` 增加只依赖标准库的单资产、有限期限线性二次控制参考。目标为 `eta*v² + lambda*sigma²*x²` 的时间积分，库存满足 `dx/dt=-v`，到期必须归零。期限和 eta 为正，初始库存、lambda 和 sigma 非负。调用者提供秒、股数及同一币种的参数；模块返回给定时刻的库存、卖出速率及剩余目标值，不处理账户、成交或参数估计。

设计：冻结的数据类和纯函数，以无量纲双曲函数比值及 expm1 处理低风险和大参数；对非有限输入及不可表示的计算域明确报错。到期库存为零时剩余目标值为零；速率取到期左极限。

步骤：先编写并观察失败的 TWAP、库存性质、数值积分、HJB 残差、边界和溢出测试；实现独立模块并运行回归；补充中英文能力边界和路线图；完成 Rust、归属与文档检查，记录结果并提交供独立审查。

审查重点：低风险消减误差、大双曲函数参数、有限输入造成的溢出、非零到期库存的奇异值，以及避免将解析参考表述为成交或校准证明。
